# Laboratories (design draft, 2026-11-20)

Status: **built 2026-11-20 on `feature/laboratories`, uncommitted; checked live on the integration server the same day (bots, no client).** Owner answers 2026-11-20: 1 yes, 2 yes, 3 yes, 4 guards now, 5 no (labs are NOT budgeted), 6 yes, 7 yes.

## What it is

Abandoned research laboratories that generate in the overworld as ordinary world structures. Players find one, explore it, and loot its
containers for AscensionLib materials. There are no runs, no timer and no instance: that is what ascensionDungeons is for. A laboratory is
something you stumble on while exploring.

Server side only, like the rest of the mod: vanilla blocks, a datapack structure (jigsaw), loot tables that drop the existing loot-form
currency items (absorbed into the wallet when carried). No client mod and no new textures needed.

## Layout (preview)

```
 surface:   collapsed hut + broken antenna, stairwell down
                      |
 level -1:  [ entry hall ]--[ corridor ]--[ storage ]      storage x1-3  (supply crates)
                 |                |
            [ dorm ]        [ server room ]                 one "special" room per lab, random
                 |                |
 level -2:  [ containment ]---[ core lab ]                  core lab x1   (research terminal = best chest)
```

Jigsaw pools: `entry` (1 variant at first, more later), `corridor`, `room` (storage, dorm, server room, containment), `core` (exactly one).
Depth 3 to 6 pieces, roughly 40 x 40 blocks, 12 to 25 blocks below the surface. Rooms are built as `.nbt` templates generated by a script
(as ascensionDungeons does with its voxel landmarks), so they can be regenerated and reviewed in a preview world.

## Loot (provisional numbers)

| Container | Per lab | Contents |
|---|---|---|
| Supply crate (barrel) | 2-4 | 6-16 Resonance Dust; 20% a Scouter; vanilla filler (iron, redstone, paper, glass bottles) |
| Specimen locker (chest, containment room) | 0-1 | 10-24 dust; 1 Facet 40%; 6% a Unique Fragment |
| Research terminal (chest, core lab) | 1 | 25-50 dust; 1-2 Facets; 12% a Unique Fragment; 3% an Ascension Sigil |

Rough expectation per lab: about 70-110 dust, 1.5-2 Facets, 0.15 Unique Fragments, 0.03 Sigils.
**Never Ascension Cores or Apex Shards** (the Tower stays the only Core source, as for Trials and dungeons).

## Decisions for the owner (recommendation first)

1. **Which mod?** AscensionLib, as world structures. (Alternative: a new authored dungeon in ascensionDungeons, instanced and timed. Not what
   "explore and find" sounds like, and I don't edit that repo unasked.)
2. **Loot per player or first come?** Per player: each player gets their own roll from each container once (stored in the SQLite store,
   keyed by container position and player), so a lab someone already emptied is still worth entering. First-come is simpler but on a shared
   server the first visitor takes everything.
3. **How common?** Overworld only, spacing 48 / separation 16 chunks (about one every 700 blocks). Only new chunks get them: existing explored
   land has none.
4. **Guards?** Owner: **now** (built). Originally proposed as phase 2. Later: lab-themed wild spawns inside (Porygon, Magnemite, Voltorb, Klink, Ditto) at a higher profile tier. Profile
   zones are per dimension today, so a per-structure tier is new contract work; not in the first build.
5. **Respect the daily budget?** Owner: **no**. Lab payouts are not counted against the daily budget.
6. **Numbers:** the table above, checked in `FaucetModelTest` beside the Tower and Trials before building. Change any you like.
7. **Name:** "Abandoned Laboratory" (`ascensionlib:laboratory`), loot tables `ascensionlib:chests/laboratory/{supply,specimen,terminal}`.

## As built (2026-11-20)

- **Loot rules:** `domain/LaboratoryLoot` (the table above, exactly). Seeded by (container, player); one store operation per (container, player)
  (`LaboratoryLoot.claimOperation`), paid with `ProgressionStore.grant` (reason `laboratory_<kind>`), so a second search replays and says
  "already searched". No new store table or schema change. `FaucetModelTest` row "Laboratory (3 crates, locker 44%, terminal)": 77.8 dust,
  1.66 Facets, 0.14 Fragments, 0.61 Scouters, 0.03 Sigils per lab per player (Tower floor 10 completion: 560 dust).
- **Containers** (`laboratory/LabContainers`): a lab container carries an EMPTY marker loot table `ascensionlib:laboratory/<kind>`. Right-click
  never opens it: the search is paid into the wallet, plus vanilla filler from `ascensionlib:chests/laboratory/<kind>` on the first search
  (Poke Balls, potions, candies; the terminal can give Up-Grade, Dubious Disc, Electirizer, Magnet, Metal Coat, Link Cable). Survival players
  cannot break one; placing a hopper, a rail or a hopper minecart within one block of one is refused (so nobody strips the marker for everyone).
  If something unpacks a marker anyway (a hopper already there, an explosion) it yields nothing and the container becomes an ordinary one.
- **Guards** (`laboratory/LabGuards`, `spawn_pool_world/laboratory.json`): Porygon, Magnemite, Voltorb, Klink, Ditto, Magneton spawn with the
  Cobblemon `structures` condition. Any wild Pokemon that spawns inside a lab piece gets `ascensionlib_zone_tier = 3` in its persistent data
  (never rename: captured Pokemon keep it). `ProfileZones.tierOf(Pokemon, dimension)` = max(dimension tier, mark), still 0 where the
  configuration turns profiles off; used by capture, the Scouter, battle rating and the admin preview. Guard tier 3 kept (owner, 2026-11-20).
- **Structure:** `tools/laboratory_structures.py` generates every file (9 templates, pools, structure, structure set spacing 48 /
  separation 16, biome tag, a decay processor, loot tables, the spawn file). Hut + 14-block ladder shaft (start piece, `start_height` -14,
  projected to the surface) -> hub (aligned vertical jigsaw) -> two halls -> one room each (storage 3, dorm 2, server room 2, containment 2)
  and the core lab (terminal + one supply crate). `tools/laboratory_preview.py` assembles labs the way the jigsaw placer does, checks overlaps,
  doorways, the ladder and the single terminal, and draws `build/laboratory-preview.png`. `LaboratoryDataTest` pins the data to the Java.
- **Live check (2026-11-20, integration server 25601, mineflayer bots + RCON; `trade-bots/lab-test.mjs`, `lab-hopper.mjs`, `lab-guards.mjs`):**
  `/locate structure ascensionlib:laboratory` found one 644 blocks from spawn; it generated whole (hut, 21-block ladder in one column, hub, both
  halls, storage room, server room, core lab; no jigsaw blocks left; maps in `build/lab-plan.png`, `build/lab-cut.png`). A Supply Crate paid
  15 dust and the Research Terminal 44 dust + 2 Facets; the second search said "already searched"; no container window ever opened; the filler
  arrived. A hopper beside a crate was refused with the message, and allowed three blocks away. Guards: the first spawn file put lab species
  all over the SURFACE (Cobblemon's `structures` condition covers the structure's whole area): 16 of 36 Pokemon there. Fixed with
  `canSeeSky: false, maxSkyLight: 10`; after the fix none spawned on the surface, the ones in the rooms (Ditto, Voltorb at y 44-45) carried
  `ascensionlib_zone_tier: 3`, and a few lab species spawned in caves under the area (y 25-31) unmarked (tier 1 there; minor).
- **Not verified:** the claim message and the look in a real client; the hut on steep slopes (terrain adaptation `none`); water from caves
  flooding rooms; a real guard battle and capture keeping tier 3 (the mark is in the Pokemon's saved data, which Cobblemon's codec keeps).
